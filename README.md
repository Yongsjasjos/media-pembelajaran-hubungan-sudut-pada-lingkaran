# Media Pembelajaran Interaktif: Sudut pada Lingkaran

Proyek media pembelajaran Matematika kelas XI yang membahas hubungan sudut pada lingkaran. Dibuat sebagai aplikasi web statis agar mudah dipublikasikan melalui GitHub Pages.

## Teknologi
- **HTML** (`index.html`): struktur halaman dan konten slide.
- **CSS** (`style.css`): tata letak, tampilan, transisi, dan animasi visual.
- **JavaScript** (`script.js`): navigasi, interaksi tombol, animasi bertahap, dan aktivitas tebak gambar.
- **SVG**: visualisasi geometri yang disisipkan pada HTML.
- **KaTeX**: perender notasi matematika, dimuat dari CDN.

## Menjalankan secara lokal
Buka `index.html` di browser modern. Koneksi internet dibutuhkan untuk memuat KaTeX dari CDN.

## Publikasi dengan GitHub Pages
1. Buat repository GitHub baru.
2. Unggah `index.html`, `style.css`, dan `script.js` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
5. Simpan dan tunggu tautan GitHub Pages tersedia.
